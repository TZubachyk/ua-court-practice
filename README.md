# ua-court-practice

**Claude-скіл `/єдрср` для пошуку, верифікації та представлення української судової практики.**

Знаходить релевантні судові рішення у [Єдиному державному реєстрі судових рішень](https://reyestr.court.gov.ua/), верифікує кожне рішення за повним оригінальним текстом і складає Word-документ із таблицею перевірених справ — з гіперлінками на ЄДРСР, локалізованими цитатами і маркерами впевненості.

## Для кого

Скіл призначений для **юристів, помічників адвокатів і студентів**, які регулярно готують підбірки судової практики для клієнтів, керівників, ментора чи власних потреб.

## Що робить

1. Питає кілька уточнюючих питань про задачу (тема, інстанція, період, кількість, стовпці).
2. Шукає практику в ЄДРСР як основному джерелі (з фолбеком на дайджести ВС і дзеркала — clarity-project, youcontrol, iplex).
3. Для кожної справи-кандидата **вичитує повний оригінальний текст** і витягує цитати дослівно, з локацією (пункт / абзац / розділ).
4. Маркує кожну справу: ✅ верифіковано в ЄДРСР або ⚠ потребує ручної перевірки.
5. Генерує `.docx` з таблицею у вашій робочій теці. Назва за дефолтом: `{YYYY.MM.DD} - {коротка тема}.docx`.
6. **Автоматично спавнить суб-агента верифікації**, який дотягує справи зі статусом ⚠ — свіжа сесія, окремий бюджет запитів, цілеспрямований пошук.

## Установка

### Варіант 1. Як плагін (рекомендовано)

```bash
# Зі свіжою версією Claude Code:
/plugin install TZubachyk/ua-court-practice
```

Після встановлення скіл доступний як `/єдрср` у будь-якому проєкті.

### Варіант 2. Вручну (клонування)

```bash
# 1. Клонуйте репозиторій
git clone https://github.com/TZubachyk/ua-court-practice.git

# 2. Скопіюйте папку скіла у вашу глобальну скіл-теку
cp -r ua-court-practice/skills/єдрср ~/.claude/skills/

# 3. Перевірте, що скіл бачиться
ls ~/.claude/skills/єдрср/
```

Після цього скіл доступний у Claude Code як `/єдрср`.

### Залежності

Скіл **автоматично перевіряє і встановлює** всі залежності при першому запуску. Працює на macOS, Linux, Windows і WSL — визначає ОС і пакетний менеджер автоматично.

```bash
# Ручний запуск (якщо потрібно):
bash skills/єдрср/scripts/setup-deps.sh
```

Що встановлюється:

| Залежність | Для чого | macOS | Linux | Windows |
|-----------|----------|-------|-------|---------|
| Python 3 + pip | Парсинг HTML, читання .docx | brew | apt/dnf/pacman | winget/choco/scoop |
| Node.js + npm | Генерація .docx | brew | apt/dnf/pacman | winget/choco/scoop |
| poppler (pdftotext) | PDF-дайджести ВС | brew | apt/dnf/pacman | choco/scoop |
| python-docx | Читання Word-файлів | pip | pip | pip |
| Playwright + Chromium | Фолбек для JS-блоків | pip | pip | pip |
| docx (npm) | Генерація Word-файлів | npm | npm | npm |

> **Примітка:** Без Playwright скіл працює, але не зможе обійти JS-блоки на clarity-project, opendatabot та CAPTCHA в ЄДРСР. З Playwright — обходить автоматично.

## Як використовувати

### Швидкий старт

У Claude Code наберіть:

```
/єдрср знайди мені практику ВС щодо відшкодування збитків за порушення прав інтелектуальної власності в господарських справах
```

Або просто опишіть задачу — скіл активується автоматично:

```
Допоможи з пошуком судової практики щодо забезпечення позову в міжнародному комерційному арбітражі. Цікавлять рішення Київського апеляційного суду та Верховного Суду.
```

### Потік взаємодії

1. Скіл коротко описує, як шукатиме (1-2 речення).
2. Ставить 8 уточнюючих питань (можна відповідати скорочено — «1 ось так; 2 дефолт; 3 5 справ»).
3. Виконує пошук і верифікацію.
4. Видає `.docx` у вашу робочу теку.
5. Дає короткий фінальний звіт: скільки справ, скільки ✅ і ⚠, ключові висновки.

### Ітеративна робота

Після генерації документа ви можете продовжити в тій же розмові:

- `Перевір справу X` — скіл попросить надіслати текст і вичитає буквально.
- `Додай ще 5 справ за 2024-2025 рр.` — скіл розширить пошук і перевипустить файл.
- `Заміни справу 3 — вона не релевантна` — скіл знайде заміну.

## Час виконання

Процес пошуку і верифікації зазвичай займає **5-15 хвилин** залежно від кількості рішень, доступності ЄДРСР та складності теми. Суб-агент верифікації додає ще 3-5 хвилин у фоновому режимі. У «бойовому» режимі (за замовчуванням) ви не бачитимете проміжних апдейтів — тільки фінальний файл і звіт.

## Ключові правила скіла

Скіл побудований навколо однієї жорсткої вимоги:

> **Жодне твердження про зміст судового рішення не пишеться без прочитання повного оригінального тексту цього рішення.**

З цього випливають такі дочірні правила:

- Гіперлінки тільки на `reyestr.court.gov.ua/Review/{reg-номер}`.
- Кожна цитата має локацію в тексті оригіналу (`п. 4.4`, `абз. 3 п. 12`, `розділ "Позиція ВС", абз. 5`).
- Кожна справа має маркер впевненості: ✅ або ⚠.
- Якщо повний текст недоступний — скіл просить надіслати текст у чат, а не вигадує.
- Вторинні джерела (дайджести, статті) — лише точка пошуку, не джерело тверджень.

Деталі — у [`skills/єдрср/references/anti-hallucination.md`](skills/єдрср/references/anti-hallucination.md).
