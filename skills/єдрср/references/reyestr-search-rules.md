# Правила пошуку в ЄДРСР

Джерело: https://reyestr.court.gov.ua/Help (станом на травень 2026)

## Доступні поля пошуку

### Контекстний пошук (текст рішення)
- Мінімум 2 символи.
- Підтримує оператори (див. нижче).

### Реквізити суду й судді
- Регіон суду.
- Найменування суду.
- ПІБ судді (можна шукати з ? замість `'` або `-`; можна з * для фрагмента).

### Реквізити справи
- Категорія справи (6-рівнева ієрархія категорій КГС/КЦС/КАС/Великої Палати).
- Номер справи (можна включенням — мінімум 3 символи, або з `*`).
- Дата вирішення (можна діапазон).

### Реквізити рішення
- Тип документа (рішення, ухвала, постанова, окрема думка, додаткове рішення, додаткова постанова).
- Дата ухвалення рішення.

---

## Логічні оператори

| Оператор | Значення | Приклад |
|---|---|---|
| `AND` | обидва терміни обов'язкові | `залучення AND "третьою особою"` |
| `OR` | хоча б один з термінів | `вирок OR постанова` |
| `NOT` | виключити термін | `рішення NOT Київ` |
| `+` | обов'язковий термін у виразі | `+"державний орган"` |
| `-` | виключити термін у виразі | `орган -Київ` |
| `( )` | групування | `Київ AND (вирок OR постанова)` |

## Спеціальні знаки

| Знак | Значення | Приклад |
|---|---|---|
| `"..."` | точна фраза в заданому порядку | `"судове рішення ухвалено"` |
| `?` | один будь-який символ | `рішення № 11?9` |
| `*` | будь-яка кількість символів (мін. 3 перед) | `металург*`, `банкрутств*` |

## Пошук судді

- Заміна `'` або `-` на `?`: `Нечуй?Левицький`
- Фрагмент зі `*`: `Нечуй*`, `Не*цький`

## Сортування результатів

- За релевантністю (за замовченням).
- За датою ухвалення рішення (за зростанням / спаданням).

## Готові комбінації для типових запитів

Приклади нижче — шаблони, які потрібно адаптувати під конкретну тему. Замінюй терміни в лапках на ключові слова свого запиту.

### 1) Конкретна стаття закону (всі варіанти написання)
```
"стаття 33 Закону" OR "ст. 33 Закону" OR "ст.33 Закону"
```

### 2) Правовий інститут + інстанція
```
"визнання патенту недійсним" AND ("Верховний Суд" OR "касаційн*")
```

### 3) Конкретний суд + правовий інститут
Фільтри: Найменування суду = потрібний суд; тип документа = «постанова»; дата від 01.01.2020.
Контекст: `"ключова фраза" AND "правовий інститут"`

### 4) Правова позиція з ключовим терміном
```
"охоронюваний законом інтерес" AND "заінтересована особа" AND "патент*"
```

### 5) Підстави задоволення / відмови
```
"відмовлено у задоволенні" AND "позов*" AND "ключовий термін"
```

### 6) Конкретний орган як учасник справи
```
"назва органу" AND ("позивач" OR "відповідач" OR "третьою особою")

## Обмеження ЄДРСР

- Реєстр має інтерактивний захист від ботів. Якщо в межах сесії ти отримуєш CAPTCHA або порожній результат — переходь до дзеркал і повертайся з конкретним reg-номером.
- Деякі категорії рішень можуть бути обмежені у відображенні (закриті засідання, державна таємниця, окремі категорії сімейних і кримінальних справ).
- Реєстр не містить рішень третейських судів і МКАС.

## Дзеркала (використовувати тільки для пошуку лідів)

Усі ці ресурси індексують або пере-індексують ЄДРСР, але **не є офіційним джерелом**. Reg-номери з них треба валідувати в ЄДРСР.

| Ресурс | URL-шаблон | Примітка |
|---|---|---|
| Clarity Project | `https://clarity-project.info/court/decision/{reg-номер}` | Найкраще для повного тексту |
| YouControl | `https://youcontrol.com.ua/(en/)catalog/court-document/{reg-номер}/` | Англомовний інтерфейс |
| ipLex | `http://iplex.com.ua/doc.php?regnum={reg-номер}` | Іноді показує тіло |
| Protocol | `https://protocol.ua/...` | Оглядові статті, не сам реєстр |
| Verdictum | `https://verdictum.ligazakon.net/document/{...}` | Окрема нумерація |
| OpenDataBot | `https://court.opendatabot.ua/...` | Метадані справ |
